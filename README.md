# llm_on_riscv

A minimal Qwen3-0.6B C++ runner built on header-only Eigen kernels, with unit
tests and a path to RISC-V/RVV optimization.

## Build

```sh
./build.sh          # Release
./build.sh -d       # Debug
```

## Run

```sh
build/src/llm/qwen3_run --tokens 785,6722,315,9625,374 --max-new 32
```

Weights are read from `models/qwen3_0.6b`, generated by
`scripts/export_qwen3_weights.py`.

## Test

```sh
ctest --test-dir build --output-on-failure
```

Each operator has `tests/test_<op>.cpp` with `ValidInputs` and, where the
kernel validates inputs, `InvalidInputs`.

## Performance

Qwen3-0.6B, float32, batch size 1, single-threaded Eigen, Release build.
Measured on an x86 dev host (i5-13490F, 8C/16T); these are not RISC-V numbers.

| prompt tokens | TTFT | prefill tok/s | decode tok/s | peak RSS |
|---:|---:|---:|---:|---:|
| 5 | 1.30 s | ~14 | 10.1 | 2.26 GiB |
| 32 | 2.09 s | 28.0 | 10.0 | 2.29 GiB |
| 64 | 3.36 s | 26.6 | 9.5 | 2.34 GiB |
| 128 | 5.75 s | 26.7 | 9.0 | 2.43 GiB |

TTFT includes about 0.95 s of warm weight load. Decode is measured over 32
generated tokens. Peak RSS is dominated by the 2.3 GB float32 weights.

## Layout

```
src/core/            Eigen operator kernels (header-only)
src/core/operators/  Tensor/Operator example layer (not used by the runner)
src/llm/             Qwen3 runner and weight loader
tests/               gtest suites
docs/                notes and ONNX operator profile
scripts/             model export and inspection utilities
```

See `docs/01_dev.md` for the operator statistics of the target model.
